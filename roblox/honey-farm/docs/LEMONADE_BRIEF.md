## What this game is

HONEY FARM is a bright, cartoon, multiplayer bee-farming tycoon. Six players each own a fenced garden plot around a central village square. On their plot they collect honey from a hive, deposit it at a bottling machine, watch jars ride a conveyor to a honey stand, collect cash, buy more bees in a Bee Shop, merge two bees of the same tier into a stronger one (50 tiers: Starter → Clover → Daisy → Strawberry → Panda → Knight → Crystal → Storm → Galaxy → Royal, then 40 colour tiers), hatch eggs for rare one-of-a-kind bees, rebirth for a permanent production boost, and buy farm upgrades. Progress saves. The hive, bottling machine and honey stand use **pressure plates** (your addition, kept); the Bee Shop keeps its E prompt. Art direction: green grass, white wooden fences, oversized flowers, warm yellow/honey accents, rounded cartoon buildings, low-poly friendly.

## How the place is built (important)

All game logic is in scripts; the map is **generated by a script when the game starts**:

- `ServerScriptService.HoneyFarm` — server scripts: `Main`, `MapBuilder`, `PlotService`, `FarmService`, `UpgradeVisuals`, `SaveService`, `RateLimiter`, `PropLibrary`, `LeaderboardService`.
- `ReplicatedStorage.HoneyFarm` — shared modules: `Config` (all numbers and colours), `FarmState`, `PlotAllocator`, `BeeAppearance`, `VariantBees`, `StudStyle`.
- `ReplicatedStorage.BeeModels` — empty folder for hand-made bee models (see below).
- `ReplicatedStorage.Assets.BeeTemplate` — the one bee model every bee tier is built from.
- `ReplicatedStorage.Props` — **empty folder for art.** Models placed here replace the block-built scenery automatically.
- `ReplicatedStorage.Remotes` — RemoteEvents.
- `StarterPlayer.StarterPlayerScripts.HoneyFarm` — all UI and visual effects.

In Edit mode the world is empty. The map (`Workspace.HoneyFarmMap`) appears when you press Play, or when you run this in the command bar to bake it for editing:

```lua
require(game.ServerScriptService.HoneyFarm.MapBuilder).Build()
```

If `Workspace.HoneyFarmMap` already exists, the game keeps it and does **not** rebuild, so anything you decorate there is preserved.

## Map layout (when baked)

`Workspace.HoneyFarmMap`
- `Ground` (560×560 studs), invisible `Boundary` walls.
- `Village` — plaza, `VillageSpawn`, `WelcomeSign`, six cottages named Village Hall, Bakery, Bee Museum, Flower Shop, Jam Cafe, Post Office, benches, flowers, leaderboard boards (no fountain any more).
- `Paths` — six paths from plaza to plots.
- `Plots` → `Plot1`…`Plot6` (100×100 studs each, gate facing the plaza). Inside each:
  - `Ground`, `Fences`, `Gate` (with `OwnerSign`), `SpawnPoint`, `WelcomeMat`
  - `Stations` → `Hive` (with `HivePressurePlate`), `FlowerPatch`, `BeeShop`, `Bottling` (with `Conveyor` and `BottlingPressurePlate`), `SellStand` (with `SellPressurePlate`)
  - `Expansion` → `HiveExpansion` pad (a block hive tree grows here as players upgrade Hive Storage, with hives hanging from its branches; leave the pad clear), `MachineExpansion` pad (extra tanks appear here)
  - `Temp` — **runtime only**; wiped whenever the owner leaves. Never put permanent things here.
- `Scenery` — trees and giant flowers between plots.

## What you (Lemonade) are for

**Art and atmosphere.** Make it look like a proper cartoon farm village:

1. **Props (preferred way).** Build or insert nice models, then name them and put them in `ReplicatedStorage.Props`:
   - `Tree` (and `Tree2`, `Tree3`… for variety), `Cottage`, `Hive`, `MiniHive`, `Jar` (the jar that rides the conveyor).
   - The game clones them, strips any scripts, anchors them, **scales them to the spot** (trees ~19–34 studs tall, cottages 22, hive 12, mini hives 7) and stands them on the ground facing the right way. Pivot/size don't matter; set a `YawOffset` attribute (degrees) if a model's front isn't its +Z face.
   - Flowers are built from petal blocks in the stud style on purpose; edit them in `MapBuilder` through Claude if the look should change.
   - Upgraded hive looks: `Hive` (level 1), `Hive2`, `Hive3`… are swapped in as the player upgrades Hive Storage. Make each one look richer than the last (more tiers, gold trim, a chimney, flags).
   - `MiniHive` is the hive that hangs from the hive tree's branches (scaled to 7 studs, hung by its top), so a rounder, nest-like hive suits it.
   - Optional attributes on a prop: `HeightScale` (number), `KeepSize` (true = don't rescale), `CanCollide` (bool).
2. **Decorate the baked map.** Bake it (command above), then add lamp posts, signs, crates, bushes, paths detail, terrain touches, lighting, skybox, anywhere in `Workspace.HoneyFarmMap`. Keep walkways clear.
3. **Re-skin stations** by adding parts around them. Fine to add roofs, flags, barrels, honeycomb textures to the hive, pipes to the bottling machine, awnings to the stands.

4. **Hand-made bees (optional).** Instead of recolouring the template, you may build full bee models and put them in `ReplicatedStorage.BeeModels`, named exactly: `Starter Bee`, `Clover Bee`, `Daisy Bee`, `Strawberry Bee`, `Panda Bee`, `Knight Bee`, `Crystal Bee`, `Storm Bee`, `Galaxy Bee`, `Royal Bee` (optionally `Shiny <name>`), or any egg bee name from `VariantBees`. Set each model's pivot so its front arrow points out of the bee's face. The game scales them automatically; no scripts inside.

## What to leave alone

- **Do not edit, rename, move or delete scripts** under `ServerScriptService.HoneyFarm`, `ReplicatedStorage.HoneyFarm`, `StarterPlayerScripts.HoneyFarm`, or the `Remotes` folder. Code changes go through the other assistant (Claude), who maintains the source.
- **Keep these part/folder names** inside each plot; scripts find things by name. You may change how they look (colour, material, extra parts around them) but not their names or remove them:
  `Base`, `HivePressurePlate`, `BottlingPressurePlate`, `SellPressurePlate` (the plates the scripts listen to), `BeeExit`, `FlowerSpots` (+ `Spot1`–`Spot9`), `Counter` (shop + stand), `Machine`, `DepositPoint`, `Conveyor`, `ConveyorStart`, `ConveyorEnd`, `StationPrompt`, `Label`, `SpawnPoint`, `OwnerSign` (+ `FrontGui`/`BackGui` with `Avatar`, `OwnerName`, `Subtitle`), `HiveExpansion`, `MachineExpansion`, `Temp`, `Stations`, `Plot1`…`Plot6` and their `PlotId` attributes.
- **Don't change** `ReplicatedStorage.Assets.BeeTemplate` (all 50 bee tiers and the egg bees are generated from it) unless the goal is to redesign *every* bee. If you do, keep its part colours: yellow body (255,255,0), dark stripes (27,42,53), light-cyan wings (159,243,233), black eyes (17,17,17); the code identifies parts by those colours.
- **Don't put anything in `Temp`** folders.
- Keep the six plots' positions and the paths; the plot layout drives spawning and ownership.

## Style notes

- Palette (from `Config.Colors`): grass `#6EC454`, path sand `#E9CD96`, wood `#B07848`, honey `#FFBE28`, deep honey `#E69614`, cream `#FFF6DC`, text brown `#462D14`. Roofs: coral, orange, teal, purple, pink, blue (one per cottage).
- Rounded, chunky, friendly shapes; low part counts (the map is ~2,450 parts; target staying under ~6,000 total for mobile).
- Camera is third-person; keep tall things away from gates and paths so the view stays clear.
